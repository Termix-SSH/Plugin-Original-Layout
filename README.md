## Overview

Original Layout brings back the look Termix had up to version 2.2.1, before the 2.3.0 redesign. Hosts sit in a floating sidebar, one card per folder. Tabs sit in a floating bar over a framed tab area, and tools like snippets open in a sidebar on the right. It comes with the old dark and light colors as two themes.

Everything else works like Classic Layout: the Dashboard, the Host Manager, Settings and the admin pages are the same. You can switch layouts in Settings, Appearance.

Read the [docs](https://docs.termix.site/plugins/original-layout) to learn how it works.

<br />

## Features

- Floating sidebar with a card for each host folder
- Host rows with a status dot, the tools you use most and a menu for the rest
- Search hosts by name or with tag:, user:, ip:, port: and folder:
- Floating tab bar with rounded tabs over a framed tab area
- Tools sidebar on the right for snippets, history and other panels
- The old dark and light colors as two themes
- Dashboard, Host Manager and Settings from Classic Layout
- Mobile bottom bar

## Support

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.
